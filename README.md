# 💰 Smart Finance Tracker (C++ / Qt)

## 📌 Опис проєкту
**Smart Finance Tracker** — це сучасний десктопний застосунок із графічним інтерфейсом (GUI) для обліку особистих доходів, витрат та управління фінансовими цілями. 

Проєкт побудований за модульною архітектурою з використанням об'єктно-орієнтованого програмування (ООП) на C++ та фреймворку Qt. Збереження даних реалізовано через локальну базу даних у форматі JSON.

---

## 🚀 Основні можливості

- 📊 **Інтерактивний Дашборд:** Візуалізація загального фінансового стану (сумарний дохід, витрати та чистий залишок балансу) в реальному часі.
- 💸 **Керування транзакціями:** Зручне додавання доходів та витрат із фіксацією суми, категорії, дати та короткого опису.
- 🏷️ **Кольорове маркування:** Візуальний розподіл фінансових потоків у таблиці (`QTableWidget`) — зелений для доходів, червоний для витрат.
- 🎯 **Модуль фінансових цілей:** Інтерактивні картки-скарбнички з динамічними смугами прогресу (`QProgressBar`) для відстеження накопичень.
- 💱 **Мультивалютний режим:** Миттєвий динамічний перерахунок усього інтерфейсу між Гривнею (грн) та Доларом ($).
- 🔒 **Валідація даних:** Розумна перевірка полів форми на помилки (підсвічування порожніх полів червоним кольором).
- 💾 **Автозбереження:** Надійна синхронізація сесії з диском завдяки перехопленню події закриття вікна в деструкторі головного класу.

---

## ⚙️ Технологічний стек

- 💻 **Мова програмування:** C++ (стандарт C++17)
- 🖼️ **Графічний фреймворк:** Qt 6 / Qt 5 (`QtWidgets`, `QStackedWidget`, `QLayouts`)
- 🗂️ **Формат даних / Сховище:** JSON (`std::vector`, файлові потоки, серіалізація через бібліотеки парсингу)
- 🛠️ **Середовище розробки:** Qt Creator / Visual Studio Code
- 🌿 **Система контролю версій:** Git

## 🧠 Перспективи розвитку (Roadmap)
Проєкт спроектовано з урахуванням легкого масштабування, у майбутньому планується:

2. Інтеграція модуля **QtCharts** для побудови красивих кругових діаграм та графіків витрат.
3. Додавання функції експорту звітів за місяць у формати **Excel (CSV)** та **PDF**.
