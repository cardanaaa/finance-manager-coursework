# 💰 Finance Manager (C++)

## 📌 Опис проєкту
Консольний застосунок, розроблений мовою **C++**, для обліку особистих доходів і витрат.  
Дозволяє ефективно керувати бюджетом, аналізувати фінансові звички та забезпечує захист даних за допомогою шифрування.

---

## 🎯 Мета проєкту
Створення простого та зручного інструменту для:
- контролю особистих фінансів 💸  
- планування витрат 📊  
- накопичення коштів 🎯  
- формування корисних фінансових звичок  

---

## ⚙️ Технологічний стек
- 💻 **Мова програмування:** C++ (C++11)  
- 🔐 **Алгоритми:** Шифр Цезаря  
- 🗂️ **Структури даних:** вектори, мапи, файлові потоки  
- 🖥️ **Платформа:** Linux / Windows  

---

## 🚀 Основні можливості
- ➕ Додавання доходів та витрат  
- 🏷️ Категоризація витрат (Їжа, Транспорт, Розваги, Інше)  
- 📉 Встановлення бюджетних лімітів  
- ⚠️ Попередження при перевищенні бюджету  
- 📊 Фінансові звіти  
- 📅 Фільтрація транзакцій за датою  
- 🔒 Шифрування даних  
- 💾 Збереження даних між сесіями  
- 🎯 Система накопичення (цілі)  

---

Проєкт розроблений з можливістю подальшого розширення:
